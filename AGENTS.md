# AGENTS.md

## Commands (run in order where noted)

| Command | What it does |
| --- | --- |
| `npm test` | Vitest (all tests in `src/core/tests/`) |
| `npx vitest run src/core/tests/icons/fileIcons.test.ts` | Single test file |
| `npm run lint` | Biome check |
| `npm run format` | `biome format --write ./src` |
| `npm run verify` | Sheriff dependency-rule check (`sheriff.config.ts`) |
| `npm run check` | Icon consistency checks (availability, conflicts, naming, folder structure) |
| `npm run check-colors` | Validate SVG colors against Material palette |
| `npm run build` | `compile` (tsc + postcompile scripts) then esbuild bundle |
| `npm run compile` | `tsc --noEmit` + declarations + JSON/open-folder/clone generation + `npm run check` |
| `npm run vscode:prepublish` | `lint + build` — what CI actually runs |
| `npm run svgo` | Optimize SVGs (removes viewBox) |
| `npm run watch` | Build watch mode via esbuild |

Build order: `npm run lint && npm run verify && npm run build` (CI: `npm test && npm run vscode:prepublish`).

## Architecture

Three package boundaries enforced by Sheriff (`npm run verify`):

- `src/core/` — icon manifest, associations, translations, models. Has tests.
- `src/extension/` — VS Code API interaction (commands, config). No tests. **Cannot** be imported by other modules.
- `src/module/` — re-exports from `core` for the npm package. Entry: `src/module/index.ts`.

Entrypoints (bundled by esbuild):

- `src/extension/desktop/extension.ts` → `dist/extension/desktop/extension.cjs`
- `src/extension/web/extension.ts` → `dist/extension/web/extension.cjs` (stub — activate is no-op)
- `src/module/index.ts` → `dist/module/index.cjs`

`tsconfig.json` is type-check only (`noEmit: true`). Real bundle is via esbuild. The icon manifest `dist/material-icons.json` is generated by `npm run generateJson` at postcompile time.

## Testing

- Vitest, setup in `src/core/tests/mocks/index.ts` (mocks `vscode` API).
- Tests exist **only** in `src/core/tests/`. No tests for extension or scripts.
- lint-staged runs `npm run test` on `src/core/**/*.{js,ts}` changes.

## Icon workflow

- SVGs live in `icons/`. Definitions in `src/core/icons/{fileIcons,folderIcons,languageIcons}.ts`.
- **Colors must be from Material Design palette** (`material-colors.yml`). Black (`#000000`) and White (`#FFFFFF`) forbidden.
- Folder SVGs: only **closed** variant committed. Must have `id="folder"` (canonical path) and `id="motive"`. Open variant auto-generated at build time. Never commit `-open.svg` files.
- Light theme variant: `_light.svg` suffix, enabled via `light: true` in config.
- High contrast variant: `_highContrast.svg` suffix, enabled via `highContrast: true`.
- Clone icons via `clone` config block (no new SVG). Use `data-mit-no-recolor="true"` on elements to prevent recoloring.
- Files `icons/file.svg`, `icons/folder.svg`, `icons/folder-root.svg`, `icons/*.clone.svg`, `icons/clones/`, and `icons/folder-*-open.svg` are gitignored (generated).
- SVGs must be 16×16 viewBox, pixel-aligned, and vectorized (no base64 images).
- Run `npm run svgo` before committing new SVGs (removes viewBox — expected).

## Conventions

- **Commits**: conventional commit format (enforced by commitlint). PR title becomes the squash commit message.
- **Pre-commit**: husky → lint-staged (lints JS/TS, runs tests on core, checks SVGs, lints markdown).
- **Code style**: Biome — single quotes, trailing commas `es5`, spaces/2, line width 80, arrow functions, const, no unused vars/imports.
- **TypeScript**: strict mode, `verbatimModuleSyntax`, `bundler` resolution, `noEmit`.

## NLS / Translations

- Extension strings: `package.nls.json` + `package.nls.<locale>.json`.
- Programmatic strings: `src/i18n/`.

## CI

All workflows in `.github/workflows/`. Main build: `npm test && npm run vscode:prepublish`. Separate workflows for color checks, folder structure, icon review, labels, PR titles.
